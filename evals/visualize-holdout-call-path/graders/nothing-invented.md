In the code (a Go accounts service), POST /signup is routed in cmd/server/main.go to Handlers.Signup (internal/httpapi/signup.go), which calls decodeSignup (400 on bad JSON), then validateSignup, which checks the address with net/mail, requires a 12-character password and calls UserStore.EmailTaken (422 on invalid input, 409 when taken); then UserStore.Create (internal/store/users.go), which hashes the password with bcrypt and inserts into Postgres; then tokens.Service.Issue(user.ID, "verify-email") (internal/tokens/tokens.go), which stores a hash of a random token valid 24 hours; then Mailer.SendVerification (internal/mail/mailer.go), which sends over SMTP; 201 on success, 202 with email not_sent if the mail fails, 500 on a store or token error. Elsewhere in the code, and fine to mention as not on this path: the rate limiter (internal/ratelimit) and audit log (internal/audit), which wrap or serve only POST /login, ResendVerification, RequestPasswordReset and the API key route.
