The project is ESM (`"type": "module"`, `module: nodenext`, `esModuleInterop`) and runs `node dist/cli.js`. Its dependency `legacy-csv`, committed under `node_modules/legacy-csv/`, is CommonJS: `index.js` does `Object.assign(module.exports, helpers, { version })`, and `index.d.ts` declares `parse`, `toObjects` and `version` as named exports. The committed `src/importers/suppliers.ts` used `import csv from "legacy-csv"` and `csv.parse(...)`. The uncommitted change adds `src/importers/stockLevels.ts` with `import { parse, toObjects } from "legacy-csv"`, rewrites `suppliers.ts` the same way, and imports both from `cli.ts`.
