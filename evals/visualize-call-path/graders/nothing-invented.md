In the code, the path is: create_order in orders/app.py, which returns 400 when the body has no items or no email, then calls OrderService.place_order in orders/service.py; place_order builds an Order, calls get_handler(self.settings.payment_provider, ...) in orders/payments/registry.py, which looks the name up in _HANDLERS and returns a CardHandler, BankTransferHandler or SandboxHandler (orders/payments/handlers.py), then charge() in orders/payments/charging.py, which calls the handler's authorize and capture; on PaymentDeclined the order is saved as payment_failed and create_order returns 402; otherwise the order is marked paid, OrderRepository.save (orders/repository.py) writes it to SQLite, and then OrderNotifier.send_confirmation (orders/notifications.py) renders the email and sends it with SmtpMailer, and create_order returns 201.

Elsewhere in the code, and fine to mention as not on this path: GET /orders/<order_id> with order_cache, POST /orders/<order_id>/charge (recharge_order) and retry_failed_payments in orders/jobs.py.
