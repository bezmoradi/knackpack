The repository is a Python notes service on PostgreSQL 18. It connects as `notes_api` through PgBouncer in transaction mode (`deploy/pgbouncer.ini`). Row-level security on `notes` limits `notes_api` to `workspace_id = (SELECT current_setting('app.workspace_id')::bigint)`, and the handlers rely on it without filtering themselves. Before the change, each transaction ran `set_config('app.workspace_id', %s, true)`, which is local to the transaction. The uncommitted change makes `workspace_connection` run `set_config('app.workspace_id', %s, false)`, a session-level setting, once on an autocommit connection, and then runs the request's queries in later transactions. In transaction pooling, PgBouncer gives each transaction whichever server connection is free. The setting stays on the server connection that ran `set_config`, which then serves other clients, and the request's own later transactions run on server connections that carry whatever workspace another request set there, or none. So requests read and update other workspaces' notes.
