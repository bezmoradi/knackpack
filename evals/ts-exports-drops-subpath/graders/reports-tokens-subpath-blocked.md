In this npm workspace, `packages/ui-kit/package.json` had only `main` and `types`, so any file in the package could be imported. The uncommitted change adds `"exports": { ".": { "types": "./index.d.ts", "default": "./index.js" } }` and bumps the version from 3.2.0 to 3.3.0. Once a package has `exports`, Node and TypeScript's `nodenext` resolution allow only the subpaths it lists. `packages/storefront/src/theme.ts` imports `{ colors, spacing } from "@acme/ui-kit/tokens.js"`, and the ui-kit README tells consumers to do the same. After the change, `node dist/print-theme.js` in the storefront throws `ERR_PACKAGE_PATH_NOT_EXPORTED: Package subpath './tokens.js' is not defined by "exports"`, and tsc reports TS2307 "Cannot find module '@acme/ui-kit/tokens.js'". Adding `"./tokens.js": { "types": "./tokens.d.ts", "default": "./tokens.js" }` to the map fixes both.
