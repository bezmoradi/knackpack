The repository's infrastructure root, infra/reports/, is applied in production by CI with OpenTofu 1.13 (`tofu plan`, then `tofu apply` on a push to main), and its README says so; nothing in the repository runs it with Terraform. The uncommitted change deletes the resource blocks for the S3 bucket `aws_s3_bucket.legacy_reports` and its `aws_s3_bucket_versioning`, and adds a `removed` block for each with no `lifecycle` block, with a comment saying the bucket is being handed over to the data team's own stack and its data must be kept. In OpenTofu 1.10 and later, a `removed` block without a `lifecycle` block removes the object from state and leaves it in place (OpenTofu also warns that the lifecycle block is missing); it destroys only with `lifecycle { destroy = true }`. So applying this change keeps the bucket, as intended. Terraform would destroy it, but Terraform doesn't apply this root.
